# QuantCliff

## 《小模型的能力边界与失效预警》

围绕"小模型的可靠性"开展三部分对照实验，回答"小模型被压缩后哪些能力先崩、哪些保底，以及能否在它开口前预判它这次会不会答错"：

1. **量化临界点（主研究）**：3 模型（Qwen3-1.7B / Qwen2.5-1.5B / Gemma-3-1B）× 7 档（Q2_K→F16）× 5 类能力 × 500 题，定位能力悬崖的位宽与形态
2. **三元退化图谱（实验 2）**：训练式 1.58-bit 三元模型 `Ternary-Bonsai-1.7B`（底模与主实验同为 Qwen3-1.7B）与 PTQ 曲线对照，检验"悬崖"是否只是训练后量化的产物
3. **失效预警探针（实验 3）**：冻结 Qwen3-0.6B，只读隐藏层激活，在模型开口前预测本轮答案对错，做成"不可靠答案拦截器"
