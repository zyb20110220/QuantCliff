# 开题方案：《小模型的能力边界与失效预警》

项目名 QuantCliff | 2026-09-26 定稿 · 2026-09-27 三项融合修订

## 1. 项目概述

一句话：**围绕"小模型的可靠性"开展三部分对照实验——量化临界点曲线（主研究）、三元量化退化图谱（实验 2）、开口前失效预警探针（实验 3），共同回答"小模型被压缩后哪些能力先崩、哪些保底，以及能否在它开口前预判它这次会不会答错"。**

三部分关系：主研究给出 PTQ"位宽—能力"曲线与悬崖；实验 2 用训练式 1.58-bit 三元模型检验"悬崖是否只是 PTQ 的产物"；实验 3 在模型开口前用隐藏层激活预测答错，形成"边界定位→失效预警"闭环。三者共用同一套 5 类能力题池与判分器，结果可比。

动机故事（答辩开场用）：手机端小模型有时会"一本正经地胡说八道"。我猜想这与模型被压缩的程度有关——于是先画压缩曲线找"悬崖"（主研究），再问两个更难的问题：悬崖能绕过去吗（三元图谱）？胡说八道能提前拦截吗（探针）？

## 2. 研究问题与假设

**研究问题（开放，不预设结论）**：

- **RQ1（衰减形态）**：量化位宽与能力损失之间的函数形态是什么——均匀衰减，还是存在悬崖式突变？（两种结果都是发现）
- **RQ2（维度差异）**：不同能力维度对量化的敏感性是否存在系统性差异？若存在，差异的模式（速率/顺序）如何？
- **RQ3（跨模型一致性）**：RQ1/RQ2 的规律在三个模型上是否一致？
- **RQ4（实用边界）**：据此能给出什么样的安全使用指南？
- **RQ5（三元 vs PTQ）**：训练式 1.58-bit 三元量化的能力落点，位于 PTQ 位宽曲线的延长线上，还是显著高于延长线——训练式量化能否绕过悬崖？
- **RQ6（失效预警）**：模型"开口前"的隐藏层激活能在多大程度上预测本轮答案的正确性？该预警能力与模型尺度（0.6B vs 1.7B）有何关系？

**待检验假设（与问题分离，允许被证伪）**：

- H1：存在悬崖，大概率位于 Q4 以下（若被证伪，"均匀衰减"本身就是有价值的发现）
- H2：生成类能力（长文/指令跟随）比知识类更敏感
- H3：退化模式跨模型一致
- H4：三元落点显著高于 PTQ 曲线延长线（训练式量化绕过悬崖）
- H5：探针 AUROC 显著优于"模型自身 softmax 置信度"基线

> 修订记录：初版 RQ 直接问"悬崖在哪"，预设了悬崖存在，经审视认为提问不严谨，遂将"是否存在悬崖"改为 RQ1 的开放检验对象。（详见 evidence.md）

## 3. 实验设计

### 3.1 主研究：量化临界点（原方案不变）

| 要素 | 定稿 |
|---|---|
| 模型 | 主：Qwen3-1.7B；验证：Qwen2.5-1.5B、Gemma-3-1B |
| 档位 | Q2_K / Q3_K_M / Q4_K_M / Q5_K_M / Q6_K / Q8_0 / F16（官方 ggml-org GGUF 全套） |
| 题量/档 | MMLU-Pro 150 + TruthfulQA 100 + IFEval 100 + C-Eval 100 + needle 4K×20 + 中文事实 30 = 500 题 |
| 总规模 | 3 模型 × 7 档 × 500 = 10,500 次推理 |
| 采样 | greedy（温度 0）全局固定，保证可复现 |
| 口径 | 相对退化率 = (F16 正确率 − 档位正确率) / F16 正确率，隔离模型基础能力差异（如 Gemma 中文弱） |
| 乱码/解析失败 | 单独统计，不混入"答错"（其本身即为退化证据） |
| 中文错字率 | 新增指标：对 C-Eval/中文事实输出统计乱码比 + 重复 n-gram 率，画入位宽曲线 |

### 3.2 实验 2：三元能力退化图谱

| 要素 | 定稿 |
|---|---|
| 核心对比 | `prism-ml/Ternary-Bonsai-1.7B`（Q2_0，436 MiB）vs Qwen3-1.7B 的 PTQ 曲线（尤其 Q2_K） |
| 底模关系 | 两者底模同为 Qwen3-1.7B——三元版是"训练式 1.58-bit"，PTQ 各档是"训练后量化"，同尺度同题池可对照 |
| 题量 | 1.7B 全套 500 题；8B 加分版 180 题（MMLU-Pro 150 + 中文事实 30） |
| 分析 | 三元点挂到主研究位宽轴（1.58bit 落 Q2_K 左侧）；5 维能力雷达图（dense F16 为基准）；中文错字率对比 |
| 8B 基线口径 | Qwen3-8B Q8_0（F16 16.4GB 超 16GB 内存），报告中注明 |

### 3.3 实验 3：开口前失效预警探针

| 要素 | 定稿 |
|---|---|
| 模型 | Qwen3-0.6B 为主（冻结，transformers + PyTorch CPU）；窗口 C 末 1.7B 加分 |
| 方法 | 取 prompt 末 token 的隐藏层激活 → sklearn 逻辑回归探针 → 预测"本轮答对/答错" |
| 训练集 | 2000 样本（MMLU-Pro + TruthfulQA + IFEval 扩充），CPU 采集约 1 小时 |
| 切分 | 按题切分训练/测试（防泄漏）；跨基准泛化测试（MMLU-Pro 训练 → TruthfulQA 测试） |
| 指标 | AUROC + ECE 校准曲线；与"模型自身 softmax 置信度"基线做 DeLong 检验 |
| 成品 | Gradio"预警拦截器"演示：提问 → 红灯/绿灯 → 再输出答案 |

## 7. 统计分析方法

1. **形态检验（回答 RQ1）**：每条位宽-正确率曲线做"线性 vs 分段（plateau-cliff）"拟合，AIC/BIC 比较 + 二阶差分峰值检验
2. **悬崖定位（仅当 H1 成立）**：变化点检测（PELT）+ 相邻档位配对 McNemar 检验
3. **维度差异（RQ2）**：标准化退化速率排序 + 显著性检验；每档正确率报告 Wilson 95% 置信区间
4. **跨模型一致性（RQ3）**：三模型退化顺序的 Kendall W 检验
5. **三元 vs PTQ（RQ5）**：三元点与 PTQ 曲线延长线的偏差检验；三元 vs Q2_K 配对 McNemar
6. **探针（RQ6）**：AUROC + ECE 校准曲线；与 softmax 置信度基线的 DeLong 检验；按题切分 + 跨基准泛化
7. 原始曲线如实报告，不预设单调（允许 Q3→Q4 回升等反常现象）

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| 数据污染（Qwen 见过 MMLU 题） | 用 MMLU-Pro（更难更新）+ 报告主动声明 |
| 结论部分可预期（4bit 以下退化） | 创新点放在细粒度中文曲线 + 能力顺序规律 + 跨模型一致性 |
| Gemma 中文弱干扰 | 相对退化率口径隔离 |
| 低档位死循环 | 输出截断 + 超时，失败率单独计数 |
| 答辩现场无网络 | 演示全离线预载 |
| Q2_0 不在主线 llama.cpp，llama-cpp-python 未必支持 | 实施时先验证主线；备选 Prism fork 编译或 ONNX 版；eval_loop 加后端适配层 |
| 8B dense 基线 16.4GB 超内存 | 基线用 Q8_0（报告注明）；仍紧张则降 Q6_K 或弃 8B |
| 探针可能只比置信度基线好一点点 | 如实报告（"预警无增益"也是有效结论）；尺度对比仍可产出 |
| 0.6B 在个别基准几乎全错→标签失衡 | 分层抽样；报告每基准可用样本数；失衡过重的基准退出探针训练 |
